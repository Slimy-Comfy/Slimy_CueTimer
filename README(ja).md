# Slimy_CueTimer


ComfyUI用の進捗モニターノードです。

=======
![Slimy_CueTimer](screenshot.jpg)

ComfyUI用のキュー進捗モニターができるアクセサリです。

レンダリング中の進行状況、処理速度、履歴、プレビューを1つのノードで確認できます。

------------------------------------------------------------------------


## 特長

-   **PeepPreviewは、KSamplerがサブグラフ内にある場合でもリアルタイム表示できます。**
-   **ノード接続が不要なため、ワークフロー内の見やすい位置へ自由に配置できます。**
=======
## 主な機能
-   **キュー実行されると自動的にタイムカウントがスタートし完了までの時間を計測します**
-   **キュー完了時にシステム通知と音でお知らせ**
-   **KSamplerが出力するプレビュー画像を表示します**
-   **PeepPreviewは、KSamplerがサブグラフ内にある場合でもリアルタイム表示できます**
-   **ノード接続が不要なため、ワークフロー内の見やすい位置へ自由に配置できます**


------------------------------------------------------------------------

## 主な機能

### プログレス表示

-   Steps進捗バー
-   Total進捗バー
-   処理速度（it/s）
-   完了率（%）
-   経過時間
-   残り時間

> **※
> Total進捗は、直近のレンダリング履歴から予測した進捗・残り時間を表示しています。**

### 履歴

-   最新5件を表示
-   ▲▼ボタンで1件ずつスクロール
-   処理終了後も履歴を保持

### PeepPreview

Kサンプラーの内部プレビュー画像をリアルタイム表示します。

表示／非表示を切り替え可能です。

### 通知

-   SystemNotify：処理終了時にシステム通知を表示
-   PeepSound：処理終了時に通知音を再生



送信にはSMTPサーバーの設定が必要です。ComfyUI初回起動時に、本ノードのフォルダ内へ
`smtp_password` などを編集してください。Gmailの場合はGoogleアカウントの
「アプリパスワード」を`smtp_password`に使用してください。

パスワードをファイルに残したくない場合は、環境変数
を設定することでも代替できます（環境変数が優先されます）。

------------------------------------------------------------------------

## 用途

-   長時間レンダリングの監視
-   バッチ処理の進行確認
-   生成画像のリアルタイム確認
-   レンダリング時間の予測

------------------------------------------------------------------------

## Desktop Widget（任意）

`DesktopApp/CueTimerDesktop.exe` から Windows デスクトップ版を起動できます。`CueTimerDesktop.exe` と `CueTimerDesktop.ps1` は同じフォルダに置いてください。CueTimer の進捗・プレビューをミラーし、既に開いている ComfyUI のブラウザタブへ移動する機能、生成完了後の動画表示に対応しています。

GitHub公開版では個人用の Email 機能を `ENABLE_EMAIL = False` にして無効化しています。
